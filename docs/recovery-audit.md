`python3 eng/audit-recovery.py` 直接读取恢复提交中的 ZIP，校验 ZIP 哈希、CRC、所选历史正文哈希，并报告当前适配情况；需要本地存在恢复分支的 Git 对象。

## 合入策略

从 main 建立整合分支，按已验证的源码正文提取，再重建缺失基础与业务模块。保留恢复分支和 ZIP 作为证据，不把记录包当作生产源码目录直接合并，也不沿用无法验证的旧迁移树。新初始迁移用于新数据库；如以后找回旧数据库，应另做映射迁移，不能把新迁移直接套到旧表上。

全部验收通过后，将整合分支快进合入 main。这样 main 同时包含现有页面和可运行后端，恢复分支继续保存原始记录。
