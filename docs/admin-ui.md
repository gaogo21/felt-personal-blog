# 管理员内容工作台

管理员界面使用 Razor、原生 JavaScript、Tiptap 与本地构建的 Tabler 1.6.1 CSS。没有引入 React，也没有新增数据库表或修改 API 路由与请求字段。

## 导航与展示

- 首页展示：画廊、自我介绍、精选文章、专栏管理。
- 内容管理：文章与随记、知识库章节、项目展览。
- 资源管理：媒体库。
- 站点维护：关于页面、备份与操作记录。

电脑使用分组侧栏，900px 以下使用导航抽屉；手机列表按条目排列。首屏毛毡人物继续使用原有展示，不增加管理入口。

## 保存规则

画廊必须有 10 张不同的就绪图片：01—05 对应第一排，06—10 对应第二排。编辑时移除图片会留下空位，只允许给空位上传或选择新图片。补齐前不能保存，公开画廊继续使用上次成功保存的版本。媒体库的总容量不受这个 10 张限制。

精选必须有 3 篇不同且可公开访问的已发布文章。排列顺序就是首页顺序。被精选引用的文章必须先替换，才能撤回、移入回收站或清空。

每个专栏保存时必须有名称、介绍和 3 张不同的就绪图片。图片 1、2、3 分别对应电脑左上、左下、右侧大图；手机则对应下左、下右、上方大图。首页按已启用专栏动态生成卡片，编号在后台、首页和详情中均按可见顺序生成。

首页自我介绍保留输入的回车、空行和空格。动画仅拆分非空白文本，换行仍保留为文本节点。后台提供电脑、手机文案预览，窄屏可自然折行。

三个首页设置页和关于页仍使用现有完整的站点设置对象。保存时合并当前模块的字段并提交已有 ETag，遇到多窗口冲突保留输入，不自动覆盖其他模块。首次配置不完整时，可在画廊页同时补齐图片与精选，一次提交完整配置；不会随机补选内容。

## 构建与依赖

```sh
npm ci --prefix frontend/admin
npm run build --prefix frontend/admin
npm test --prefix frontend/admin
```

构建只复制 Tabler CSS 与许可到 `src/Blog.Web/wwwroot/vendor/tabler/`，不会部署 Tabler 示例应用或额外插件。版本和完整性哈希保存在 npm 锁文件中。Docker 和验证工作流模板均包含此构建步骤。

许可副本来自 [Tabler 官方仓库](https://github.com/tabler/tabler/blob/dev/LICENSE) 与 [Bootstrap v5.3.8](https://github.com/twbs/bootstrap/blob/v5.3.8/LICENSE)，保存在 `frontend/admin/third-party/`，并一起复制到发布资源目录。
